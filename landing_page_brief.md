# 🐢 Kura Landing Page Brief

# 🎯 Purpose

The landing page is NOT meant to be:
- a marketing funnel
- a SaaS homepage
- a feature-heavy website

The landing page exists to:

> help visitors immediately understand what Kura is before logging in.

The goal is emotional clarity.

Visitors should understand within 15–30 seconds:
- what Kura is
- how the system works
- why it feels different from normal fitness apps

Primary CTA:

```text
Start Training With Kura
```

This button redirects users directly to the login page.

---

# 🧠 Product Positioning

Kura is:
- beginner-friendly
- emotionally-driven
- consistency-focused
- companionship-oriented

Kura is NOT:
- performance-focused
- streak-focused
- competitive
- analytics-heavy

The emotional core:

> Your real-life runs help Kura grow stronger and prepare for the final race.

---

# ✅ Simplifications For MVP

## Keep It Single Page

Do NOT create:
- About page
- FAQ page
- Blog page
- Contact page
- Extra routes

For MVP:

```text
Landing Page → Login Page
```

That is enough.

---

## Keep Navigation Minimal

Avoid:
- complicated navbar
- dropdown menus
- multiple links

Simple is better.

Potentially only:
- logo/title
- CTA button

---

## Avoid Fancy Animations

Do NOT spend time on:
- parallax
- complex transitions
- advanced scroll effects
- animation debugging

Simple fade-ins are optional.

Static sections are completely fine.

---

## Use Existing Assets Only

Do not delay development to create:
- new illustrations
- custom scenes
- multiple character art

Use:
- existing Kura sprite
- simple background
- clean layout

---

## Keep Text Short

The landing page should be easy to scan quickly.

Avoid:
- long lore dumps
- giant paragraphs
- overexplaining mechanics

Curiosity is stronger than excessive explanation.

---

# 🧭 Recommended Landing Page Structure

# 1. Hero Section

## Purpose
Immediately explain Kura.

---

## Content
- Kura sprite
- headline
- one-line explanation
- CTA button

### Example

```text
Help Kura Train For The Final Race

Your real-life runs help a tiny turtle
grow stronger and run farther.

[ Start Training With Kura ]
```

---

# 2. How It Works Section

## Purpose
Quickly explain the core gameplay loop.

---

## Content
Simple 3-step flow:

```text
You Run
↓
Kura Improves
↓
The Journey Continues
```

Keep it minimal.

No complex diagrams needed.

---

# 3. Philosophy Section

## Purpose
Reduce beginner intimidation.

---

## Explain
- beginner-friendly
- no streak pressure
- no need to run fast
- consistency matters more than speed

### Example

```text
No streak pressure.
No need to run fast.
Even small runs help Kura improve.
```

---

# 4. Story Hook Section

## Purpose
Create curiosity and emotional tension.

---

## Example

```text
Somewhere beyond the hills,
AR. Nab is still waiting.

Nobody knows how far he can run.
```

Keep this section very short.

---

# 5. Final CTA Section

## Purpose
Encourage users to begin immediately.

---

## CTA

```text
[ Start Training With Kura ]
```

Redirect directly to login page.

---

# 🏗️ Recommended Build Order

Designed for:
- beginner-friendly implementation
- one-session completion
- minimal complexity
- fast visible progress

---

# STEP 1 — Basic Layout Structure

## Goal
Build the full page structure quickly.

---

## Checklist
- [ ] Create Hero section
- [ ] Create How It Works section
- [ ] Create Philosophy section
- [ ] Create Story Hook section
- [ ] Create Final CTA section

Focus on structure only.

Do NOT focus on styling perfection yet.

---

# STEP 2 — Add Kura Visual

## Goal
Add emotional identity to the page.

---

## Checklist
- [ ] Add Kura sprite/image
- [ ] Position image properly
- [ ] Ensure mobile sizing works

Avoid animation work during this phase.

---

# STEP 3 — Add Styling

## Goal
Make the page feel warm and readable.

---

## Checklist
- [ ] Add spacing
- [ ] Add typography hierarchy
- [ ] Add background colors
- [ ] Style CTA button

Visual direction:
- soft
- clean
- cozy
- beginner-friendly

---

# STEP 4 — Mobile Optimization

## Goal
Ensure the page works well on phones.

---

## Checklist
- [ ] Prevent overflow
- [ ] Ensure readable text
- [ ] Ensure CTA visibility
- [ ] Ensure spacing consistency

This is important because most users will likely visit from mobile.

---

# STEP 5 — Connect CTA Routing

## Goal
Complete the user flow.

---

## Checklist
- [ ] Redirect CTA button to login page
- [ ] Test navigation flow
- [ ] Test mobile interaction

---

# 🚫 Things To Avoid During Development

Do NOT suddenly add:
- extra pages
- lore systems
- advanced animations
- soundtrack
- dark/light mode toggle
- testimonials
- analytics
- feature overload

The landing page should remain:
- simple
- emotionally clear
- easy to finish

---

# 🎯 Success Metric

The landing page succeeds if users immediately understand:

```text
My runs help Kura grow stronger.
```

NOT if the page looks overly polished.

Clarity is the real objective.
